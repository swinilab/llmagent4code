# Order Management System (OMS)

A production-grade backend-only e-commerce Order Management System built with Python, FastAPI, and SQLAlchemy.

## Features

- Customer management
- Product catalog
- Order processing workflow
- Payment processing
- Invoice generation
- RESTful API with OpenAPI documentation
- Dockerized for easy deployment
- Designed for high concurrency and fault tolerance
